=== THE SELECTION CUT-OFF ===

Set in agent/common.py (currently 5.0). Override without editing:
    set RISK_THRESHOLD=6.0        (or put RISK_THRESHOLD=6.0 in .env)
    python run_poc.py --showcase --threshold 6

A component is selected when EITHER its risk or its impact reaches the cut-off.


=== .env FLAGS ===

JIRA_LIVE=1         read defects from Jira instead of the bundled CSV
CHANGE_LIVE=1       read this release's features/fixes from Jira
REPORT_BUGS=1       let --demo file a real Jira defect
APPROVE_ALL=1       open the approval gates (demo mode); 0 to watch them pause

features:  project = KAN AND labels = "release-delta" AND labels = "feature"
bug-fixes: project = KAN AND labels = "release-delta" AND labels = "bugfix"
Each issue's component comes from its labels; type is tagged feature / bugfix.
